# The Drone Stand for Potensic Atom Series

This project is created by Shin ZHENG. Aug 02, 2025.

Currently maintained by [Shin ZHENG](shin.zheng@foxmail.com).

## Overview

This stand is designed for the Potensic Atom series drones, allowing you to display your drone securely.

The main goal of this project is to create a delicate and stable stand that is compatible with both Potensic Atom and Atom2 drones.

For extra stability, you can add a metal weight to the bottom of the stand. See the sample image for installation instructions.

Please use and test with caution!

I cannot guarantee full compatibility with all printed models. Use these models at your own risk.

## Known Issues

It is highly recommended to use a high-precision SLA 3D printer and ensure your printer can produce accurate threads.

Compatibility note:

- When used with Atom1 or Atom2, the drone may not fit perfectly around the hump near the ToF sensor.

If you find any other issues, please let me know and I will try to fix them: shin.zheng@foxmail.com

Happy hacking.
