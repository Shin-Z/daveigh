# DAveiGh: **D**rone **A**ccessories and **G**adgets 3D Printed

This project is created by Shin ZHENG. Oct 10, 2023.

Currently maintained by [Shin ZHENG](shin.zheng@foxmail.com).

## Overview
DAveiGh offers a collection of 3D-printable drone accessories and gadgets (mostly .stl files), such as lens hoods and filter holders.

Some of these accessories and gadgets are not available on the market, so I designed and 3D-printed them myself! The models may not be perfect, and print quality depends on your 3D printer’s accuracy.

Please use and test these models with caution!

I cannot guarantee full compatibility for all printed models. Use them at your own risk.

If you find any issues, please let me know and I will try to fix them: shin.zheng@foxmail.com

Happy hacking!
